# aiGlossar

Kurzdefinitionen der Begriffe, die im Arbeitsalltag mit AI-Systemen vorkommen. Einige davon sind neu, andere sind deutlich älter als Sprachmodelle und werden nur neu angewendet.

Jeder Eintrag hat zwei bis drei Sätze Definition, wo es sich lohnt eine Einordnung, und eine Zeile mit Links. Die Einordnung sagt, wie fest ein Begriff sitzt, wo er uneinheitlich verwendet wird und womit man ihn verwechseln kann. Wo die Mehr-Zeile fehlt, gibt es zu dem Begriff keine belastbare herstellerneutrale Quelle, die über die Definition hinausgeht.

Die Begriffe stehen englisch, weil sie im Arbeitsalltag englisch gesprochen werden. Erklärt wird auf Deutsch.

Stand: August 2026
