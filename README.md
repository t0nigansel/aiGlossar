# aiGlossar

Ein Glossar der Begriffe aus der Arbeit mit KI-Systemen.

Definitionen gibt es überall. Was hier dazukommt, ist die **Einordnung**: wo ein Begriff wackelt, wo er doppelt belegt ist, womit man ihn verwechselt und was in der Herstellerdokumentation fehlt.

Drei Beispiele aus dem Bestand:

> **Harness** — Für die Qualitätssicherung die interessanteste Schicht, weil hier die Grenzen tatsächlich durchgesetzt werden. Was im Prompt steht, ist eine Bitte. Was im Harness steht, ist eine Regel.

> **ACP** — Das Kürzel ist doppelt belegt. Es steht sowohl für Agent Client Protocol als auch für Agent Communication Protocol. Vor der Diskussion klären, welches gemeint ist.

> **Hallucination** — Das Wort legt eine Störung nahe. Tatsächlich ist es das Normalverhalten eines Systems, das wahrscheinliche Fortsetzungen erzeugt. Aus Modellsicht besteht kein Unterschied zwischen einer richtigen und einer erfundenen Antwort.

## Warum datiert

Die Bedeutungen bewegen sich derzeit schnell. Ein Eintrag ist deshalb kein Urteil, sondern ein Messpunkt mit Datum. Verschiebt sich eine Bedeutung, kommt der neue Stand dazu, statt den alten zu ersetzen. Die Commit-Historie wird damit zum Bewegungsprofil der Begriffe.

Fehlt bei einem Eintrag die Quellenzeile, gibt es zu dem Begriff keine belastbare herstellerneutrale Quelle, die über die Definition hinausgeht. Das Weglassen ist eine Aussage.

**Stand: August 2026**

## Mitmachen

Widerspruch ist der nützlichste Beitrag. Wer eine Einordnung für falsch oder überholt hält, macht bitte ein Issue auf, gern mit Beleg.

Für neue oder geänderte Einträge gilt **[STYLE.md](STYLE.md)** als verbindliche Regel.

## English

A glossary of the vocabulary that comes with working on AI systems.

Definitions are everywhere. What this adds is the **assessment**: where a term is unstable, where it carries two different meanings, what it gets confused with, and what vendor documentation leaves out.

Entries are dated on purpose. Meanings are moving fast right now, so an entry is a measurement with a timestamp rather than a verdict. When a meaning shifts, the new reading is added rather than replacing the old one, which turns the commit history into a record of how the vocabulary moved.

Disagreement is the most useful contribution. If an assessment looks wrong or outdated, please open an issue. Entry rules live in [STYLE.md](STYLE.md).
